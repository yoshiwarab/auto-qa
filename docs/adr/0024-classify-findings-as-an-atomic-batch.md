# Classify Findings as an atomic batch

After each execution batch, Auto-QA creates one `classify-findings` Job containing one new unclassified Finding for every Attempt with its Scenario, mechanical result, cause, summary, and Evidence Bundle links. This includes success Findings from mechanically passing Attempts so the agent judges their screenshots and accessibility snapshots in the same batch as failures. The agent must classify every listed Finding exactly once in one atomic submission before routing begins, giving it cross-result context and avoiding a separate Turn or Job type for visual review; later execution batches create their own classification Jobs.

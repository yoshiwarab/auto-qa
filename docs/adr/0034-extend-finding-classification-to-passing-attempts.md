# Extend Finding classification to passing Attempts

Auto-QA v1 will create one Finding from every Attempt, including a success Finding from each mechanically passing Playwright Attempt. The existing atomic `classify-findings` Job will require the external coding agent to inspect runtime-captured screenshots and accessibility snapshots for success Findings as well as failure evidence, then classify each as `verified-success` or an existing issue category permitted by its cause. The Scenario Runtime owns automatic final-state capture and bounded named checkpoints, while the Workflow Engine sees only durable Evidence Bundle references. This extends the established judgment loop instead of adding a separate visual-review Job, and it adds agent perception without making the agent the live browser executor, allowing it to erase deterministic failures, or introducing an embedded model provider.
